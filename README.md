# 🎮 Simon Says Game

A simple and interactive **Simon Says memory game** built using **HTML, CSS, and JavaScript**.

The game challenges players to remember and reproduce an increasingly long sequence of colored buttons. With every successful round, the difficulty increases as a new color is added to the sequence.

## 🚀 Live Demo

You can run the game locally by opening `simon.html` in your browser.

---

## ✨ Features

* 🎯 Keyboard-based game start
* 🔴 Four colored game buttons
* 🧠 Memory-based sequence gameplay
* 📈 Increasing difficulty with each level
* ✨ Game and user button animations
* 🏆 High-score tracking using `localStorage`
* 💥 Game-over detection
* 🔄 Automatic game reset
* 📱 Responsive viewport configuration

The interface contains four buttons: **Red, Yellow, Green, and Purple**.

## 🎮 How to Play

1. Open the game in your browser.
2. Press any key to start.
3. The game will flash one colored button.
4. Remember the color shown.
5. Click the same button.
6. A new color will be added to the sequence.
7. Repeat the complete sequence correctly.
8. Each successful round increases your level.
9. If you select the wrong color, the game ends.
10. Your score and high score are displayed after game over.

The game starts only once when the user presses a key, after which `levelUp()` generates the first sequence item.

## 🧠 Game Logic

The game maintains two arrays:

```javascript
let gameSeq = [];
let userSeq = [];
```

* `gameSeq` stores the sequence generated by the game.
* `userSeq` stores the sequence entered by the player.

Four possible colors are stored in the `btns` array:

```javascript
let btns = ["yellow", "red", "purple", "green"];
```

At every level, a random color is selected and added to the game sequence.

### Sequence Checking

Whenever the player clicks a button, the selected color is added to `userSeq`.

The game then compares the user's latest input with the corresponding item in `gameSeq`.

If the complete sequence is correct, the next level starts automatically. If the player makes a mistake, the game ends and the high score is updated when applicable.

## 🎨 Button Animations

The game uses two visual effects:

### Game Flash

The selected button temporarily receives the `.flash` class.

```css
.flash {
    background-color: white;
}
```

### User Flash

When the player clicks a button, it temporarily receives the `.userflash` class.

```css
.userflash {
    background-color: green;
}
```

These effects provide visual feedback during gameplay.

---

## 🏆 High Score

The game uses browser `localStorage` to save the player's high score.

```javascript
localStorage.setItem("highscore", highscore);
```

This allows the high score to remain available even after the game is restarted or the page is refreshed.
